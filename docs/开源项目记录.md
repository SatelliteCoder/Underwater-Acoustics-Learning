# 水声学开源项目记录

更新时间：2026-08-14

说明：

- 本表优先收录公开可访问、适合学习或复现的项目。
- 许可证以项目原仓库为准，使用前请再次核验。
- “学习价值”用于帮助读者决定先看什么，不代表项目质量排名。

## 1. 水声传播与声场建模

| 项目 | 方向 | 语言/平台 | 学习价值 | 链接 |
| --- | --- | --- | --- | --- |
| Acoustics Toolbox | BELLHOP、KRAKEN、SCOOTER、SPARC 等经典传播模型 | Fortran / MATLAB 接口 | 水声传播建模核心工具箱，适合从理论到工程输入输出全链路学习 | [OALIB](https://oalib-acoustics.org/website_resources/AcousticsToolbox/) |
| AcousticsToolbox.jl | Acoustics Toolbox 的 Julia 封装 | Julia | 学习如何把经典模型封装成现代语言接口 | [GitHub](https://github.com/org-arl/AcousticsToolbox.jl) |
| UnderwaterAcoustics.jl | 水声传播建模框架 | Julia | 适合学习传播模型抽象、环境对象、仿真接口设计 | [GitHub](https://github.com/org-arl/UnderwaterAcoustics.jl) |
| AcousticRayTracers.jl | 声学射线追踪 | Julia | 学习射线模型、几何声学与可复用求解器设计 | [GitHub](https://github.com/org-arl/AcousticRayTracers.jl) |
| VirtualAcousticOcean.jl | 虚拟声学海洋环境 | Julia | 适合学习海洋环境与声学仿真的组合方式 | [GitHub](https://github.com/org-arl/VirtualAcousticOcean.jl) |
| arlpy.uwa | 水声传播与信道工具 | Python | Python 生态中比较友好的水声入门工具，含 BELLHOP 调用与传播损失处理 | [GitHub](https://github.com/org-arl/arlpy) |
| BELLHOP CUDA / C++ variants | BELLHOP 加速与现代化改写 | CUDA / C++ | 可作为学习传播模型性能优化和工程移植的参考 | [GitHub](https://github.com/A-New-BellHope/bellhopcuda) |

## 2. 阵列信号处理、声呐与声学 DSP

| 项目 | 方向 | 语言/平台 | 学习价值 | 链接 |
| --- | --- | --- | --- | --- |
| arlpy.bf | 波束形成与阵列处理 | Python | 入门 Bartlett、Capon、MUSIC 等阵列处理方法 | [GitHub](https://github.com/org-arl/arlpy) |
| Acoular | 麦克风阵列与声源定位 | Python | 虽主要面向空气声学，但波束形成、阵列处理方法可迁移到水声学习 | [GitHub](https://github.com/acoular/acoular) |
| pyroomacoustics | DOA、阵列、声学仿真 | Python | 通用声学工具，适合学习 STFT、DOA、波束形成的代码组织 | [GitHub](https://github.com/LCAV/pyroomacoustics) |
| scipy.signal | 通用信号处理 | Python | 滤波、谱估计、相关、STFT 等水声数据处理基础 | [GitHub](https://github.com/scipy/scipy) |
| GNU Radio | SDR 与通信信号处理 | C++ / Python | 水声通信原型验证可借鉴其流图和模块化思想 | [GitHub](https://github.com/gnuradio/gnuradio) |

| DESERT Underwater | 水声网络协议与仿真 | C++ / Tcl / ns-2 | 经典水声网络仿真框架，适合学习 MAC、路由、物理层抽象 | [GitHub](https://github.com/signetlabdei/DESERT_Underwater) |
| Aqua-Sim-NG | ns-3 水声网络仿真 | C++ / ns-3 | 适合学习 ns-3 下水声网络模块设计 | [GitHub](https://github.com/rmartin5/aqua-sim-ng) |
| WOSS | World Ocean Simulation System | C++ | 将海洋环境、声传播与网络仿真结合的工具 | [GitHub](https://github.com/signetlabdei/WOSS) |
| UnetStack | 水声网络协议栈 | Java / Groovy | 偏工程协议栈和仿真，适合了解水声网络系统设计 | [GitHub](https://github.com/org-arl/unet-contrib) |
| AHOI modem | 开源水声调制解调器 | C / Embedded / Hardware | 适合学习低成本水声通信硬件、固件与上位机接口 | [官方 Git 仓库入口](https://www3.tuhh.de/acps/projects/ahoi/resources_git/) |
