# 常用网站与工具

## 水声传播与模型

| 名称 | 用途 | 链接 |
| --- | --- | --- |
| Ocean Acoustic Library | 水声传播模型、文档、测试用例 | [OALIB](https://oalib-acoustics.org/) |
| Acoustics Toolbox | BELLHOP、KRAKEN、SCOOTER 等模型 | [Acoustics Toolbox](https://oalib-acoustics.org/website_resources/AcousticsToolbox/) |
| arlpy documentation | Python 水声、阵列、信号处理文档 | [Docs](https://arlpy.readthedocs.io/) |
