# 项目详细解析

本文对应 README 首页中的“详情”链接，用于说明每个项目为什么值得学习、适合放在哪个水声学学习阶段，以及使用时需要注意什么。外部项目的许可证、版本和维护状态可能变化，使用前请以原仓库或官方网站为准。

## 声场传播与仿真

<a id="acoustics-toolbox"></a>
### Acoustics Toolbox

[Acoustics Toolbox](https://oalib-acoustics.org/website_resources/AcousticsToolbox/) 是水声传播建模中最经典的工具箱之一，包含 BELLHOP、KRAKEN、SCOOTER、SPARC 等模型。它适合用来学习射线模型、简正波模型、频域/时域传播模型的输入输出格式和物理假设。

学习重点：

- BELLHOP 的 `.env` 文件、声线轨迹、传播损失和到达结构。
- KRAKEN 的分层波导、简正波和低频浅海传播。
- 模型适用边界：高频/低频、深海/浅海、水平不变/距离相关环境。

注意事项：工具箱偏传统 Fortran/MATLAB 工作流，适合先用示例跑通，再逐步理解每个输入参数。

<a id="arlpy"></a>
### arlpy

[arlpy](https://github.com/org-arl/arlpy) 是 Python 工具库，包含水声传播、信号处理、阵列波束形成和机器人相关模块。对学习者很友好，因为它能把经典水声模型以 Python 方式调用起来。

学习重点：

- `arlpy.uwa`：水声传播、BELLHOP 接口、传播损失和到达结构。
- `arlpy.bf`：Bartlett、Capon、MUSIC 等阵列波束形成。
- 用 Python 把环境参数、仿真结果和后处理串起来。

适合场景：入门水声仿真、快速验证声呐方程、做小型教学 demo。

<a id="underwateracousticsjl"></a>
### UnderwaterAcoustics.jl

[UnderwaterAcoustics.jl](https://github.com/org-arl/UnderwaterAcoustics.jl) 是 Julia 生态中的水声建模框架。它适合学习如何用现代科学计算语言表达“环境 - 声源 - 接收器 - 传播模型”的抽象。

学习重点：

- 用类型系统组织海洋环境和传播模型。
- 与 Acoustics Toolbox、射线追踪模型等工具的关系。
- 高性能计算语言在水声仿真中的设计思路。

适合场景：研究型复现、框架设计学习、高性能水声建模。

<a id="acousticstoolboxjl"></a>
### AcousticsToolbox.jl

[AcousticsToolbox.jl](https://github.com/org-arl/AcousticsToolbox.jl) 是 Julia 调用 Acoustics Toolbox 的封装。它的学习价值不只在于“能跑模型”，还在于展示了如何把传统模型接入更现代的数据结构和工作流。

适合关注：

- 传统水声程序的现代语言封装。
- 输入文件生成、模型执行、输出解析的自动化。
- Julia 与 Fortran/MATLAB 生态的衔接方式。

<a id="acousticraytracersjl"></a>
### AcousticRayTracers.jl

[AcousticRayTracers.jl](https://github.com/org-arl/AcousticRayTracers.jl) 关注声学射线追踪。对理解声线弯曲、本征声线、声道和到达结构很有帮助。

学习重点：

- 声速梯度下射线如何弯曲。
- 声线与传播损失、到达时间之间的关系。
- 射线模型在高频声呐和深海传播中的优势与失效区域。

<a id="virtualacousticoceanjl"></a>
### VirtualAcousticOcean.jl

[VirtualAcousticOcean.jl](https://github.com/org-arl/VirtualAcousticOcean.jl) 更偏“虚拟声学海洋”的系统抽象，适合把声源、接收器、海洋环境和传播模型统一起来。

适合场景：

- 做声场仿真平台的架构参考。
- 设计可复用的海洋环境和声学场景对象。
- 将传播仿真与通信、定位或感知任务结合。

<a id="bellhopcuda"></a>
### bellhopcuda

[bellhopcuda](https://github.com/A-New-BellHope/bellhopcuda) 是 BELLHOP 相关的 GPU/CUDA 加速实现线索。它适合学习如何把计算量大的射线追踪任务并行化。

学习重点：

- 声线追踪的并行粒度。
- GPU 加速在大范围声场预报中的价值。
- 传统科学代码向 C++/CUDA 迁移时的工程问题。

## 声呐与感知装备仿真

<a id="uuv-simulator"></a>
### UUV Simulator

[UUV Simulator](https://github.com/uuvsimulator/uuv_simulator) 是 ROS/Gazebo 下的水下机器人仿真框架，可用于 UUV 动力学、控制、传感器插件和任务流程仿真。

学习重点：

- UUV 六自由度运动和水动力模型。
- Gazebo 传感器插件扩展方式。
- 将声呐、DVL、IMU、相机等感知装备接入机器人仿真。

注意事项：原项目生态相对偏 ROS1，做新项目时可参考思想，但需要关注依赖版本。

<a id="dave"></a>
### DAVE

[DAVE](https://github.com/Field-Robotics-Lab/dave) 是 Field Robotics Lab 面向水下机器人仿真的环境，继承和扩展了 UUV Simulator 的思路。

学习重点：

- 水下机器人任务仿真的工程组织。
- 海流、浮力、传感器和环境交互。
- 用 Gazebo/ROS 做 UUV 感知与控制实验。

<a id="isaac-sim-underwater"></a>
### Isaac Sim Underwater

[IsaacSim_Underwater](https://github.com/AntoineRichard/IsaacSim_Underwater) 面向 NVIDIA Isaac Sim 水下场景扩展。它适合关注现代仿真平台、合成数据生成和机器人感知研究的人。

适合场景：

- 合成视觉/声呐数据生成。
- 水下机器人强化学习或感知算法测试。
- 与现代 GPU 仿真平台结合。

<a id="stonefish"></a>
### Stonefish

[Stonefish](https://github.com/patrykcieslak/stonefish) 是海洋机器人仿真库，覆盖水下动力学、传感器和场景交互。它不局限于声学，但对 UUV 平台仿真很有参考价值。

学习重点：

- 海洋机器人动力学和传感器模拟。
- 仿真环境中传感器、控制器和任务的组织方式。
- 为声呐或声学定位模块提供平台背景。

<a id="sonar-simulation"></a>
### sonar_simulation

[sonar_simulation](https://github.com/Field-Robotics-Lab/sonar_simulation) 是 Field Robotics Lab 的声呐仿真相关项目，可作为 ROS/Gazebo 中生成成像声呐数据的参考。

适合学习：

- 前视声呐或成像声呐数据如何在机器人仿真中表达。
- 声呐观测与机器人位姿、环境模型之间的关系。
- 声呐 SLAM 和感知算法的数据入口。

<a id="sonar-litreview"></a>
### sonar-litreview

[sonar-litreview](https://github.com/RobustFieldAutonomyLab/sonar-litreview) 是成像声呐、声呐 SLAM 和水下机器人声呐感知方向的文献/资源索引。

适合用途：

- 快速找到成像声呐感知论文。
- 梳理声呐 SLAM、目标检测、语义分割等研究方向。
- 为后续复现选择论文和数据集。

## 水声数据处理与可视化

<a id="espresso"></a>
### Espresso

[Espresso](https://github.com/alexschimel/Espresso) 是免费开源的水柱声呐可视化和处理应用，用于多波束回声测深仪采集的水体数据。用户提供的 Word 文档中特别提到它可做垂直回声积分，并从“上方”可视化声学异常。

学习重点：

- 多波束水柱数据如何组织、读取和展示。
- 水柱异常如何通过垂直积分变成平面可视化结果。
- 从原始声呐文件到测线级 demo 的处理流程。

适合场景：水柱数据解析、水体目标/气泡/鱼群异常展示、多波束数据可视化。

<a id="coffee"></a>
### CoFFee

[CoFFee](https://github.com/alexschimel/CoFFee) 是 alexschimel 维护的多波束/水柱处理工具生态中的核心线索之一，适合研究 Kongsberg 等多波束文件解析和声呐数据处理流程。

学习重点：

- 多波束文件结构和数据字段。
- 水柱数据解析结果是什么、如何存储。
- 与 Espresso 等上层可视化工具之间的关系。

<a id="noaa-water-column-sonar-viewer"></a>
### NOAA Water Column Sonar Viewer

[NOAA Water Column Sonar Viewer](https://www.ncei.noaa.gov/maps/water-column-sonar/) 是 NCEI 提供的水柱声呐数据地图入口，适合查找、浏览和下载真实水柱声呐数据。

适合用途：

- 找真实测线和水柱样例。
- 理解公开水柱数据的空间分布、任务元数据和下载方式。
- 给教学 demo 或算法验证找原始数据。

<a id="ncei-wcsd-aws"></a>
### NCEI Water Column Sonar Data on AWS

[NCEI Water Column Sonar Data on AWS](https://registry.opendata.aws/ncei-wcsd-archive/) 是水柱声呐数据的开放云归档入口。它适合大规模数据处理和批量下载。

学习重点：

- 云端海洋声呐数据归档方式。
- 原始水柱数据批处理流程。
- 与本地解析工具、可视化工具和数据库的衔接。

<a id="echopype"></a>
### echopype

[echopype](https://github.com/OSOceanAcoustics/echopype) 面向科学回声测深数据处理，强调把仪器原始数据转换成标准化、可分析的数据结构。

学习重点：

- echosounder 数据格式标准化。
- 与 `xarray`、NetCDF、Zarr 等科学数据生态结合。
- 渔业声学、海洋生物声学和水柱数据处理流程。

<a id="pyecholab"></a>
### pyEcholab

[pyEcholab](https://github.com/noaa-afsc-mace/pyEcholab) 是 NOAA AFSC MACE 维护的 Python 回声测深数据处理工具，适合读取和处理 EK60/EK80 等科学声呐数据。

适合学习：

- 原始 echosounder 数据的 Python 解析。
- 声学回波数据标定、切片和可视化。
- 渔业声学软件工程实践。

<a id="mb-system"></a>
### MB-System

[MB-System](https://github.com/dwcaress/MB-System) 是多波束测深和海洋测绘领域的经典开源工具链。它偏海底地形和测绘，但对声呐数据、测线、地理参考和海底边界建模非常有价值。

适合学习：

- 多波束测深数据处理。
- 海底地形生成和质量控制。
- 为声传播模型提供 bathymetry 输入。

<a id="xarray"></a>
### xarray

[xarray](https://github.com/pydata/xarray) 是多维标注数组处理库，常用于 NetCDF、Zarr、海洋环境场和声场结果处理。

在水声中的用途：

- 管理 `range-depth-frequency-time` 多维声场。
- 处理 Argo、Copernicus、GEBCO 等海洋环境数据。
- 与 `dask` 结合做大规模声学数据处理。

## UUV 与环境噪声、声景分析

<a id="pamguard"></a>
### PAMGuard

[PAMGuard](https://github.com/PAMGuard/PAMGuard) 是被动声学监测领域常用开源平台，适合实时或离线处理水听器数据。

学习重点：

- 被动声学监测流程：采集、检测、分类、定位、标注。
- 海洋哺乳动物声学事件检测。
- 工程化 PAM 系统如何组织模块。

<a id="manta"></a>
### MANTA

[MANTA](https://bitbucket.org/CLO-BRP/manta-wiki/wiki/Home) 即 Making Ambient Noise Trends Accessible，用户文档中也提到它用于实现研讨会技术建议、比较海洋声景并识别环境噪声趋势。

学习重点：

- 长期水下环境噪声统计。
- 不同项目间声级比较的一致性问题。
- 海洋声景作为生态和环境观测指标的处理流程。

<a id="marina"></a>
### Marina

[Marina](https://github.com/NEFSC/READ-PSB-Marina) 是 NOAA Northeast Fisheries Science Center 被动声学研究组的工具集合。用户文档中提到它于 2020 年上线，目标是把常用数据处理工具集成到一个应用中。

适合学习：

- 被动声学常用小工具如何被组织成应用。
- 声学数据处理、标注、统计和工作流集成。
- NOAA 生态声学研究团队的工程实践。

<a id="marinebioacousticsrc"></a>
### MarineBioAcousticsRC

[MarineBioAcousticsRC](https://github.com/MarineBioAcousticsRC) 组织下聚合了 Tethys、MANTA、Triton 等海洋生物声学工具，是被动声学和海洋哺乳动物研究的重要入口。

适合用途：

- 从组织维度查找相关工具。
- 学习声学元数据、检测结果和长期声景分析工具链。
- 查找海洋生物声学软件生态。

<a id="tethys"></a>
### Tethys

[Tethys](https://github.com/MarineBioAcousticsRC/Tethys) 面向被动声学元数据管理和检测结果组织。它适合学习大型 PAM 项目如何管理数据、检测结果和标注信息。

学习重点：

- 声学数据元数据结构。
- 检测结果、时间范围、传感器和物种信息的组织。
- 被动声学数据库与分析软件的接口。

<a id="ketos"></a>
### Ketos

[Ketos](https://github.com/meridian-acoustics/ketos) 是面向水下声学机器学习的 Python 工具，适合做声谱图切片、训练数据准备和检测/分类模型训练。

适合场景：

- 海洋哺乳动物叫声检测。
- 船舶噪声分类。
- 水下声事件深度学习基线。

<a id="opensoundscape"></a>
### OpenSoundscape

[OpenSoundscape](https://github.com/kitzeslab/opensoundscape) 是生态声学和声景机器学习工具。虽然不只面向水下声学，但其声谱图分类、迁移学习和数据集管理能力可迁移到水声任务。

学习重点：

- 声谱图深度学习工作流。
- 数据增强、切片、模型训练和评估。
- 生态声学方法迁移到水声识别。

## 水声通信、网络与定位

<a id="desert-underwater"></a>
### DESERT Underwater

[DESERT Underwater](https://github.com/signetlabdei/DESERT_Underwater) 是水声网络仿真经典框架，主要用于协议栈、MAC、路由和物理层抽象研究。

学习重点：

- 水声信道长时延、低带宽、高误码对网络协议的影响。
- ns-2 生态下的仿真实验组织。
- 水声网络论文复现实验配置。

<a id="woss"></a>
### WOSS

[WOSS](https://github.com/signetlabdei/WOSS) 即 World Ocean Simulation System，用于把海洋环境、声传播模型和网络仿真连接起来。

适合学习：

- 网络仿真中如何引入真实海洋环境。
- 传播损失、时延和信道条件如何影响通信协议。
- 环境数据库与声学模型耦合。

<a id="aqua-sim-ng"></a>
### Aqua-Sim-NG

[Aqua-Sim-NG](https://github.com/rmartin5/aqua-sim-ng) 是 ns-3 生态中的水声网络仿真模块，适合学习现代网络仿真框架下的水声协议评估。

适合场景：

- 水声传感器网络。
- MAC/路由协议性能评估。
- 端到端仿真实验。

<a id="unetstack"></a>
### UnetStack

[UnetStack contrib](https://github.com/org-arl/unet-contrib) 是 UnetStack 生态的扩展入口，偏工程协议栈、仿真和水声 modem 接口。

学习重点：

- 水声网络协议栈的工程抽象。
- modem、仿真器和协议脚本如何交互。
- 从通信实验走向系统集成。

<a id="ahoi-modem"></a>
### AHOI modem

[AHOI modem](https://www3.tuhh.de/acps/projects/ahoi/resources_git/) 是低成本开源水声调制解调器项目，覆盖硬件、固件和上位机接口。

适合学习：

- 水声通信硬件原型。
- 低成本 modem 的信号链路和协议接口。
- 真实水池/外场通信实验组织。

<a id="nm3-python-driver"></a>
### NM3 Python driver

[NM3 Python driver](https://github.com/bensherlock/nm3-python-driver) 提供 NM3 水声 modem 的 Python 驱动和虚拟网络测试能力。

适合学习：

- 水声 modem 串口协议。
- 虚拟水声网络测试。
- 日志、命令和实验脚本组织。

<a id="raspi2usbl"></a>
### Raspi2USBL

[Raspi2USBL](https://github.com/GSO-soslab/Raspi2USBL) 是低成本 USBL 声学定位实验线索，适合理解声学定位硬件、时延测距和方位估计的基本工程流程。

注意事项：定位系统对同步、阵列标定、声速估计和多途抑制非常敏感，学习时应把它看作实验原型，而不是直接可工程部署的完整系统。

## 目标识别与机器学习

<a id="deepship"></a>
### DeepShip

[DeepShip](https://github.com/irfankamboh/DeepShip) 是水下船舶噪声分类常用数据/基准入口之一。适合做船型识别、深度学习分类和特征工程实验。

学习重点：

- 船舶辐射噪声的声谱图表示。
- 数据划分和类别不平衡问题。
- CNN、Transformer、时频特征等分类方法。

<a id="shipsear"></a>
### ShipsEar

[ShipsEar](http://atlanttic.uvigo.es/underwaternoise/) 是经典船舶水下辐射噪声数据集，常用于船型分类和水声目标识别入门。

适合学习：

- 小规模船舶噪声数据的预处理。
- MFCC、谱图、调制谱等特征。
- 传统机器学习与深度学习对比。

<a id="scikit-maad"></a>
### scikit-maad

[scikit-maad](https://github.com/scikit-maad/scikit-maad) 面向生态声学特征和声景分析。它可用于水声声景的特征提取与长期监测指标分析。

适合学习：

- 声学指数。
- 时频特征和事件检测前处理。
- 生物声学方法向水声数据迁移。

<a id="librosa"></a>
### librosa

[librosa](https://github.com/librosa/librosa) 是 Python 音频分析基础库。它不是水声专用，但在水声目标识别中常用于声谱图、MFCC、滤波器组和音频切片。

注意事项：水声信号的采样率、频段和噪声统计与语音/音乐不同，使用 librosa 时要按水声任务重新设定窗口、频带和增强策略。

<a id="torchaudio"></a>
### torchaudio

[torchaudio](https://github.com/pytorch/audio) 是 PyTorch 生态音频库，适合构建水声深度学习前端、数据增强和模型训练流水线。

适合用途：

- 声谱图/梅尔谱图生成。
- 数据增强与批处理。
- 与 PyTorch 分类、检测和增强模型结合。

## 信号增强、阵列处理与声学 DSP

<a id="pyroomacoustics"></a>
### pyroomacoustics

[pyroomacoustics](https://github.com/LCAV/pyroomacoustics) 是通用声学仿真与阵列处理库，包含 DOA、波束形成、STFT 等方法。虽然面向空气声学较多，但许多算法思想可迁移到水声阵列处理。

<a id="acoular"></a>
### Acoular

[Acoular](https://github.com/acoular/acoular) 是 Python 阵列声源定位工具，适合学习波束形成、阵列成像和声源定位的软件结构。

迁移价值：

- 阵列几何管理。
- 频域波束形成。
- 声源图像和空间谱可视化。

<a id="scipysignal"></a>
### scipy.signal

[scipy.signal](https://github.com/scipy/scipy) 是水声数据处理最常用的底层工具之一，提供滤波、谱估计、相关、STFT、窗函数等基础算法。

适合学习：

- 匹配滤波和到达时间估计。
- Welch PSD、谱图和滤波器设计。
- 水声通信和声呐信号处理基础。

<a id="noisereduce"></a>
### noisereduce

[noisereduce](https://github.com/timsainb/noisereduce) 是音频降噪工具，适合做水声信号增强的简单基线。

注意事项：水声环境噪声可能非平稳，多途和目标信号也可能与噪声频带重叠，因此不能简单把语音降噪结论直接套用。建议作为 baseline，而不是最终方法。

<a id="asteroid"></a>
### asteroid

[asteroid](https://github.com/asteroid-team/asteroid) 是深度音频源分离框架。它不是水声专用，但适合学习深度增强、源分离、掩膜估计和端到端音频网络。

迁移方向：

- 舰船噪声与环境噪声分离。
- 生物声事件增强。
- 多源水声混合信号分离。

## 开放数据集与环境数据

<a id="noaa-passive-acoustic-data"></a>
### NOAA Passive Acoustic Data

[NOAA Passive Acoustic Data](https://www.fisheries.noaa.gov/national/science-data/passive-acoustic-data) 是 NOAA 被动声学数据和项目入口，适合查找长期海洋声学监测数据。

适合用途：

- 声景统计。
- 海洋哺乳动物检测。
- 船舶噪声和环境噪声分析。

<a id="watkins-database"></a>
### Watkins Marine Mammal Sound Database

[Watkins Marine Mammal Sound Database](https://cis.whoi.edu/science/B/whalesounds/) 是海洋哺乳动物声音资料库，适合生物声学入门和叫声识别任务。

<a id="dclde"></a>
### DCLDE

[DCLDE](https://www.soest.hawaii.edu/ore/dclde/) 是 Detection, Classification, Localization, and Density Estimation 相关数据和挑战入口，适合海洋哺乳动物检测、分类、定位和密度估计研究。

<a id="argo"></a>
### Argo

[Argo](https://argo.ucsd.edu/) 提供全球温盐深剖面。水声传播仿真中，Argo 数据常用于生成声速剖面。

<a id="copernicus-marine"></a>
### Copernicus Marine

[Copernicus Marine](https://marine.copernicus.eu/) 提供全球和区域海洋再分析、预报和观测产品，可用于构建三维声速场、海流场和环境背景。

<a id="gebco"></a>
### GEBCO

[GEBCO](https://www.gebco.net/) 提供全球海底地形，是构建声传播海底边界和 UUV 场景地形的重要数据源。

<a id="teos-10"></a>
### TEOS-10 / Gibbs SeaWater

[TEOS-10](https://www.teos-10.org/software.htm) 提供海水热力学工具箱，可用于声速、密度、盐度和温度相关物理参数计算。

## 论文、标准与资料入口

<a id="ocean-acoustic-library"></a>
### Ocean Acoustic Library

[Ocean Acoustic Library](https://oalib-acoustics.org/) 是水声传播模型和经典资料的重要入口。学习 Acoustics Toolbox 时应优先阅读其中的模型说明、测试例和相关参考文献。
