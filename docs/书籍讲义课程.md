## 推荐学习路线

### 第一阶段：声学和信号处理基础

| 主题 | 学习目标 |
| --- | --- |
| 傅里叶变换与谱分析 | 能读懂声谱图、功率谱密度、窄带/宽带信号 |
| 采样与滤波 | 能处理水听器原始时序数据 |
| 相关与匹配滤波 | 能理解主动声呐、通信同步和到达时间估计 |
| 阵列基础 | 能理解波束形成、阵元间距、空间混叠 |

### 第二阶段：水声传播

| 主题 | 对应工具 |
| --- | --- |
| 声速剖面与传播损失 | arlpy、Acoustics Toolbox |
| 射线模型 | BELLHOP、AcousticRayTracers.jl |
| 简正波模型 | KRAKEN |
| 抛物方程模型 | RAM、SCOOTER/SPARC 相关资料 |
| 环境不确定性 | Argo、Copernicus Marine、GEBCO |

### 第三阶段：工程与论文复现

| 方向 | 建议实践 |
| --- | --- |
| 船舶噪声分类 | ShipsEar / DeepShip + Python 深度学习 |
| 被动声学监测 | PAMGuard / Ketos / OpenSoundscape |
| 水声通信 | DESERT Underwater / Aqua-Sim-NG / AHOI |
| 声场建模 | BELLHOP 环境文件、传播损失图、到达结构 |
