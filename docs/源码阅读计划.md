# 源码阅读计划

这个页面用于把“开源项目列表”变成真正能学进去的路线。

## 推荐顺序

### 1. arlpy

目标：先用 Python 快速跑通水声传播和阵列处理。

建议阅读：

- `arlpy.uwa`：水声传播接口与 BELLHOP 调用方式
- `arlpy.bf`：波束形成算法
- 示例代码：传播损失、到达结构、宽带/窄带波束形成

输出笔记：

- BELLHOP 环境参数如何组织
- 传播损失图的输入输出含义
- Bartlett、Capon、MUSIC 的适用场景

### 2. Acoustics Toolbox

目标：理解经典水声模型的输入文件、输出文件和物理假设。

建议阅读：

- BELLHOP：射线模型、环境文件、arrivals、TL 图
- KRAKEN：简正波模型、低频远程传播
- SCOOTER / SPARC：频域/时域相关模型

输出笔记：

- 每个模型适合什么频率、距离和海底条件
- `.env` 文件关键字段
- 如何做简单 benchmark

### 3. UnderwaterAcoustics.jl

目标：学习现代科学计算语言如何组织水声仿真框架。

建议阅读：

- 环境对象
- 传播模型接口
- 与 Acoustics Toolbox / ray tracer 的关系

输出笔记：

- Julia 的类型系统如何表达声学模型
- 与 Python/MATLAB 封装的差异

### 4. DESERT Underwater / Aqua-Sim-NG

目标：理解水声通信网络仿真的层次结构。

建议阅读：

- 物理层信道抽象
- MAC 协议
- 路由协议
- 仿真实验配置

输出笔记：

- 水声网络仿真与无线电网络仿真的不同点
- 传播时延、带宽、丢包模型如何进入协议评估

### 5. PAMGuard / Ketos / OpenSoundscape

目标：从数据处理角度学习被动声学监测。

建议阅读：

- 音频导入与切片
- 频谱图生成
- 标注与检测
- 模型训练与评估

输出笔记：

- 一个水声事件检测数据集需要哪些元数据
- 如何避免数据泄漏
- 如何评估检测和分类结果
