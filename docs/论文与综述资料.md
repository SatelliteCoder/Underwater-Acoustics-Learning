# 论文与综述资料

本页整理与水声开源工具、数据集和学习路线强相关的论文、标准、综述与资料入口。许多论文可能不开放全文下载，请通过 DOI、学校图书馆、作者主页或出版社正规渠道获取。

<a id="iso-18405"></a>
## ISO 18405 Underwater Acoustics Terminology

入口：[ISO 18405](https://www.iso.org/standard/62406.html)

用途：统一水下声学术语，尤其适合规范 README、项目文档、声景分析报告和数据集说明中的术语表达。

学习建议：

- 建议把它作为术语表来源，而不是教程。
- 写“声景”“声压级”“噪声级”“传播损失”等概念时要注意参考量和单位。

<a id="manta"></a>
## MANTA 与海洋声景标准化

入口：[MANTA wiki](https://bitbucket.org/CLO-BRP/manta-wiki/wiki/Home)

MANTA 的背景是让环境噪声趋势更易访问、更可比较。它强调不同硬件、采样协议和信号处理方法之间的可重复性和一致性，适合学习长期海洋声景数据处理和报告规范。

适合配合阅读：

- 海洋声音作为 Essential Ocean Variable 的相关资料。
- 被动声学监测中的声级统计、频带统计和长期趋势分析论文。
- ISO 18405 术语标准。
